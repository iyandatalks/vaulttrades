# Founders 30 Days Mentorship

- Access is visible on Profile but locked unless `users.mentorship_enrolled = true`.
- Enrollment is associated with the authenticated user's email/account.
- Program duration: 30 days, approximately 1 hour per day.
- Days 1–5 are currently available; Days 6–30 can be added later.
- Completion requires 3,600 active seconds tracked by the app. The Google Slides/Drive resource opens separately; the app cannot technically verify the external video's playback state.
